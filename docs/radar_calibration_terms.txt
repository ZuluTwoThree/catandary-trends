# Kalibrier-Korpus des Horizont-Radars — 50 Technologiefelder
#
# Format:  Begriff | Domäne | reguliert(1/0)
#
# Auswahlprinzip: nicht die 50 interessantesten Felder, sondern 50, die den
# Messbereich AUFSPANNEN. Ein Kalibrierkorpus aus lauter Emerging Tech würde nur
# beweisen, dass das Radar H3 sagen kann. Deshalb bewusst gemischt:
#
#   * Reifegrad     — diffundiert (Li-Ion, Wärmepumpe, EV, mRNA) bis
#                     vorwettbewerblich (Xenotransplantation, Neuromorphic)
#   * Regulierung   — Regime vorhanden (Pharma, Novel Food, Nuklear, Luftfahrt)
#                     vs. keines (Batterien, Chips, Software)
#   * Jurisdiktions-Spreizung — Felder, die in US und EU nachweislich AUSEINANDER
#                     liegen (Cultivated Meat, Gentherapie, autonomes Fahren,
#                     GLP-1) sind die eigentliche Prüfung: ein Radar, das überall
#                     dasselbe sagt, misst nichts.
#   * Korpus-Dichte — von ~100 bis ~20.000 Signalen, damit die Schwellen an
#                     beiden Rändern belastet werden.
#
# `reguliert` = eine behördliche Zulassung gattet den Marktzugang tatsächlich.
# Falsch gesetzt kappt es den Markt (bei 1) oder lässt Blockaden verschwinden
# (bei 0) — das Feld ist Teil der Prüfung, nicht bloß Konfiguration.
